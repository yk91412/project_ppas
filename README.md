## **소개**

**PPAS (Paper Patent Ai Search)**

AI  기술의 발전은 우리 사회에 많은 변화를 가져오고 있습니다.

이에 따라, 최신 기술 동향을 파악하는 것이 중요해졌습니다.

저희 웹은 이러한 필요에 부응하여, AI 관련 특허와 논문 정보를 종합적으로 제공합니다.

정보는 AI가 발달하기 시작한 10년전부터 제공합니다.


## **주요 기술 스택**

    • 프론트엔드: HTML, CSS, JavaScript
    
    • 백엔드: Flask
    
    • 주요 라이브러리: pandas, matplotlib, zipfile, okt



## **주요 역할**

**<웹 개발>**

- 사용자 검색 환경 구축
- 웹 사이트 전체적인 디자인 및 UI/UX 구현
- 전체 프로젝트의 구조 변경 및 최적화

**<백엔드>**

- 특허 결과 필터링 및 출력 / 원본 링크 제공
- 출원인 통계 / 유망기업 정보 제공

**<데이터 전처리 및 분석>**

- 데이터 전처리
- 데이터 분석을 통해 인사이트 도출 및 시각화 작업 수행


## **기술적 기여 및 개인적인 성취**

     - 웹 개발 : UI/UX를 구현하면서 프로젝트 최적화 경험
    
     - 백엔드 개발 : flask 활용 및 pandas로 원하는 결과 필터링
     
     - 데이터 전처리 및 분석 : okt를 활용하여 데이터 전처리 하는 방법 터득, 분석을 통한 인사이트 도출 경험
